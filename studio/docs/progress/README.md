| File | What it is |

| `ROSW_Complete_Record.md` | Six documents in one file, compiled 17 November 2026: the updated Part 1 and Part 2 progress reports, Part 3 (18 October to 17 November), the Phase 4 Planning document, the Skillification Plan and the Owner Profile and Capacity Addendum. These are the owner's records, not a tool. Nothing in the studio reads them, and no pipeline writes them. The Complete Record is a compiled file: edit its source documents, not this copy, and recompile. The owner keeps a fuller version with personal details; it is not in this repository.
