Start here

One repo, three tools for making things with Claude Code

ROSW keeps each tool in its own folder: its code, its data and its docs together. Every tool works in checkpoints. It stops, shows you what it did, and waits for you before going on. Nothing lands in a vault without a preview and an explicit yes.

creative-writing/

Creative writing

An Obsidian vault of 63 works, and a six-stage pipeline that turns an idea into a new piece in the author's own modes: essay, horror prose, epic fantasy or confessional poetry. A causal-ledger checker keeps stories to but and therefore.

What it does →
studio/

Studio

Makes one thing at a time through six checkpointed stages. It leaves a note that says how the thing was made and what is decided about it. Nothing is made before every constraint it needs is sourced.

What it does →
plugins/ui-design/

UI design plugin

A Claude Code plugin with a local catalog of UI styles, palettes, fonts, UX rules, icons, motion and stacks, and a generator that turns a query into a contrast-checked design system.

Quick start

  1. Get the repo. 
    git clone https://github.com/groot99-droid/Pipelines-Plugin.git
cd Pipelines-Plugin
  2. Install the few Python packages. The search tools need none; the pipelines read YAML. 
    pip install -r creative-writing/pipeline/requirements.txt
pip install -r studio/pipeline/requirements.txt
  3. Add your keys, if you need any. Most people need none to start: the creative-writing script's default backend is a local Ollama model, and the Claude Code skills use Claude itself. If you want Gemini or the Anthropic API, run 
    python docs/setup_keys.py
    A page opens in your browser. Paste a key, press Save, done. Keys go to ~/.rosw/keys.env in your user folder, never into the repo. More about keys.
  4. Open Claude Code in the repo folder. The creative-writing and studio skills load automatically. They are also a plugin, rosw, which works with this repo as your working folder: 
    /plugin marketplace add groot99-droid/Pipelines-Plugin
/plugin install rosw@rosw
    For the UI design plugin, start with 
    claude --plugin-dir ./plugins/ui-design
    or install it (see UI design → Install).
  5. Ask for what you want. "Develop a horror story from this idea…", "Make a UI direction for our ops console…", "Pick a palette and fonts for a spa booking site…". The matching skill is picked from its description.

Requirements

  • Python 3.10 or newer on your PATH as python.
  • Claude Code, for the skills and agents. The creative-writing pipeline also has a standalone script that needs no Claude Code at all.
  • Optional: Ollama for fully offline drafting, and Obsidian to browse the two vaults.
