Reach: reading the internet

Agent Reach is a small program that checks, for your machine, which of 15 platforms Claude can read (web, search, YouTube, Reddit, GitHub, Bilibili, RSS and more), installs what is missing when you say so, and points each platform at its own upstream tool. It is imported here whole, with its history. Other tools build small skills on top of it.

On this page: The base · Toolsets · Using it · What it does not do

The base

agent-reach/ is the program: agent-reach doctor reports each platform, and agent-reach install only checks unless you add --system. After that, Claude calls the upstream tools directly. Its settings, cookies and tokens live in ~/.agent-reach/, outside every project, and Claude never reads them.

Toolsets

A toolset is a small skill that uses the base for one job: research for a story (reach-research), outside references for the studio (reach-references), sources for a game teardown (udgt-field-research). Each declares the channels it uses, starts from agent-reach doctor --json, reads only, and treats everything fetched as untrusted reference that is never passed off as the author's words. The full list and the rules are in agent-reach/TOOLSETS.md.

To give another skill (yours, or one from anywhere) internet access, use the reach-connect skill in the reach plugin. It maps the skill's questions to channels, adds a checked Reach block, and never changes the skill's own gates.

Using it

pipx install "git+https://github.com/groot99-droid/Pipelines-Plugin.git#subdirectory=agent-reach"
agent-reach doctor
/plugin install reach@rosw        # optional: the setup and routing skills as a plugin
cd agent-reach && python -m pytest tests -q

What it does not do

  • It never posts, comments or likes, and never logs in for you.
  • It never installs system tools without your yes.
  • It does not write into the vaults, the gates or the teardown answers.
