UI design plugin

Gives Claude a local, searchable catalog of UI design decisions, and a generator that turns a query into a contrast-checked design system. Visual choices then come from curated data instead of being invented from memory.

On this page: Install · The catalog · Using it · Design systems · Skills and agents · What it writes · Maintaining it

Install

In Claude Code:

/plugin marketplace add groot99-droid/Pipelines-Plugin
/plugin install ui-design@rosw

Or, to try it from a clone for one session without installing:

claude --plugin-dir ./plugins/ui-design

Once installed, names carry the plugin prefix: /ui-design:ui-design-catalog. You rarely type them. Describe the UI work, and the skill is picked from its description.

Requirements: Python 3 on your PATH. The catalog scripts use only the standard library and never touch the network. If Python is missing, the plugin says so and falls back to the written rules in references/. No API key is needed.

Using it

Inside Claude Code, just ask: "choose a palette and fonts for a spa booking site", "what are the focus rules for a modal", "review this page's accessibility". The scripts also work on their own, from any folder:

python plugins/ui-design/catalog/scripts/search.py "keyboard focus modal" --domain ux
python plugins/ui-design/catalog/scripts/search.py "suspense streaming" --stack nextjs
python plugins/ui-design/catalog/scripts/route.py "an invoicing app for freelancers"

Route a free-worded brief first. A search only matches the catalog's own words (invoice finds the right row where invoicing does not). route.py translates the brief into the right domains and queries, and warns when a literal search would have ranked the wrong product first. ROUTER.md explains the choices, and INDEX.md lists the catalog's vocabulary.

Design systems

python plugins/ui-design/catalog/scripts/search.py "beauty spa wellness service" --design-system
python plugins/ui-design/catalog/scripts/search.py "beauty spa wellness service" --design-system -f dtcg

This produces a whole-product recommendation: style, palette with contrast checked, type pairing, effects and anti-patterns. It can come out as W3C tokens or a shadcn/ui block.

Skills and agents

NameKindWhat it does
ui-design-catalogskillSearches the catalog and generates design systems. Claude reaches for it whenever a task changes how something looks, moves or is interacted with
ui-design-multipartskillFor a wide brief (four or more parts), splits the searches across agents; for a built page, reviews four areas in parallel. Cross-checks the answers
ui-design-search-partagentRuns exactly one search from a router manifest
ui-design-page-revieweragentReviews one area of one page (a11y and touch, layout, type-colour-style, or motion) and cites a real rule for every finding
ui-design-catalog-refreshskillMaintainers only: refreshes the Google Fonts and Phosphor data and stops for approval
ui-design-catalog-revieweragentMaintainers only: checks one refresh diff for licences, columns and counts

Every agent is read-only and none persists anything. Whatever an agent returns is treated as data, never as instructions.

What it writes, and what it does not

  • Nothing, by default. Searching, routing, reviewing and generating only print.
  • --persist is the one way it writes to your project, and only with an explicit --output-dir, which Claude confirms with you first. It creates design-system/<project>/ (MASTER.md, tokens.json, theme.css, pages/) and skips existing files unless you allow --force.
  • No network. The catalog ships inside the plugin.
  • Permission prompts: a plugin cannot grant itself permission to run commands, so Claude Code asks before it runs the plugin's python scripts unless you have allowed them.

Maintaining it

Everything that needs a dependency, the network or a secret lives in maintenance/. One command runs all ten gates and prints the exact command to re-run whichever fails:

pip install -r plugins/ui-design/maintenance/requirements.txt
python plugins/ui-design/maintenance/verify.py

Refreshing the Google Fonts data live needs GOOGLE_FONTS_API_KEY (see Keys). Promoting a refreshed candidate is an editorial decision with a licensing dimension, so the refresh skill always stops for a maintainer's approval. Run it from a clone, not an installed copy: an installed plugin's folder is discarded on update.
