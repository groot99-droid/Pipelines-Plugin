plugins/video-editor/

Video editor

Edit video by conversation. A short questionnaire picks one recipe, so vertical vs landscape and dialogue vs action work never compete. It runs on your machine with ffmpeg and local Whisper, and needs no API keys for any of the editing.

On this page: Recipes · Optional extras · Publishing · Using it · What is not verified

Recipes

  • Highlight clips: pull the best moments from long dialogue; optional 9:16 reframe (centre crop, speaker pan, split screen) and captions.
  • Long-form edit: one polished video: cut retakes, grade, caption, check the cuts.
  • Action montage: cut on every strike or beat from the audio; no speech needed.
  • Animated overlays (add-on): text cards built in, a small Remotion template, Manim on demand.

Optional extras

Each is installed only if you want it, and the base stays light. speech-plus (whisperX) tightens word timing and can label speakers; stems (Demucs) separates music from speech or isolates drums; publish adds the publisher. Remotion needs Node and is not open source: free for individuals, for-profit organisations of up to three people and non-profits, otherwise a company licence.

Publishing

ve publish uses each platform's official API only: no passwords, no cookies, no browser automation. It is a dry run until you pass --yes, one platform at a time, and it is private or draft by default wherever a platform has one. Bluesky and X have no private mode, so they refuse without --public, and X also needs --accept-cost because it charges per post. A ledger stops the same post being sent twice. Credentials live in your OS keyring or in environment variables, never in a file. ve publish handoff needs no API at all: it tells you where to upload and what caption to paste.

Using it

/plugin marketplace add groot99-droid/Pipelines-Plugin
/plugin install video-editor@rosw
python plugins/video-editor/bin/ve.py doctor        # what is installed, by name only
python -m unittest discover -s plugins/video-editor/tests

What is not verified

  • ve publish has never been run against a live account. It follows the platforms' official docs and is tested against a fake network and a local server; plugins/video-editor/UNVERIFIED.md lists what to check on first real use.
  • Speaker labels (whisperX diarization) need a Hugging Face token and were not run; real footage and real speech were not used, only synthetic test clips.
  • Local Whisper normalizes fillers, so removing "um" and "uh" is best-effort.
