Setup

Your API keys

Most of ROSW needs no key at all. You need one only to draft with Gemini or the Anthropic API, or to refresh the font catalog. Keys are saved in your user folder, never in the repo, so they cannot be committed by accident.

To save keys, open this page from the helper. In the repo folder, run:

python docs/setup_keys.py

It opens this page again, connected to a small server that runs only on your own computer (127.0.0.1) and stops when you press Done. The page cannot save anything without it.

Saving to ~/.rosw/keys.env. Leave a field empty to keep what is saved. After saving, the page shows only whether a key is set; the value is never shown or sent back.

Which key do I need?

KeyToolNeeded whenGet one
GEMINI_API_KEYCreative writingDrafting or the librarian runs on Gemini (PIPELINE_LLM_BACKEND=gemini_mcp or LIBRARIAN_BACKEND=gemini_mcp)Google AI Studio
ANTHROPIC_API_KEYCreative writingThe standalone script drafts with the Anthropic API (PIPELINE_LLM_BACKEND=anthropic)Anthropic Console
GOOGLE_FONTS_API_KEYUI designA maintainer refreshes the Google Fonts catalog liveGoogle Fonts Developer API

Not needed: the Claude Code skills (they use Claude itself), the script's default Ollama backend, the studio, and everything else in the UI design plugin.

How the keys are used

  • Creative writing: creative-writing/pipeline/llm.py reads ~/.rosw/keys.env on start. A value there wins over one set in your shell.
  • UI design: the plugin stays self-contained, so its refresh reads the key from your shell. Load it from the file first: 
    # PowerShell
$env:GOOGLE_FONTS_API_KEY = ((Get-Content "$HOME\.rosw\keys.env" | Select-String '^GOOGLE_FONTS_API_KEY=').Line -split '=', 2)[1]

# bash / zsh
export "$(grep '^GOOGLE_FONTS_API_KEY=' ~/.rosw/keys.env)"
  • Somewhere else? Set ROSW_KEYS_FILE to another path before running the helper or the pipeline.
  • Had a key in creative-writing/pipeline/.env? That older location still works, but python docs/setup_keys.py --migrate moves the key into your user folder and deletes the file from the repo.

Never paste a key into a chat, a command line, an issue, or any file in the repo. If one ever leaks, revoke it at the provider and make a new one.
