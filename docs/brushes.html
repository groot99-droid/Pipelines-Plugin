Brushes

A library of Procreate brushes you can search by what they do, and a designer that opens a brush, changes it and writes a brush file back. It reads the real Procreate format byte for byte, so a brush you do not touch comes out identical. Everything runs on your machine with the standard library; search needs no embedding model and no network.

On this page: The library · Finding a brush · The designer · Using it · What is not verified

The library

990 brushes

597 from your own packs, 393 from Procreate's official sets

65 sets, 64 notes

One Obsidian note per brushset, with a section for every brush

Original files kept

The brush files themselves are committed through Git LFS, with each pack's licence recorded

Every brush is read from its archive and described by facts the code computes: its kind (stroke or stamp), spacing, taper, pressure response, whether it carries its own shape and grain image, and about fifty other settings. A notes folder, brushes/vault/, opens in Obsidian. The generated part of a note is rewritten from the catalog; whatever you write under its ## Notes heading is never touched.

Finding a brush

Search is a stdlib TF-IDF over one chunk per brush, with a closed tag vocabulary on six axes (medium, mark, texture, edge, motif, use) that Claude fills in by looking at Procreate's own stroke thumbnails. It works on names, sets and computed facts from the start, and gets better as brushes are tagged. A similar mode compares two brushes' settings.

The designer

A browser app served from your machine only (127.0.0.1, with a token made for each run). Open a brush from the library, from a file or as a new brush; edit its settings in panels generated from the format's own key list; replace its shape or grain image; paste a settings patch that Claude proposed, check it against the server and apply it as one undo step; then export a .brush or a .brushset. The page sends only the keys you changed, and the server does the encoding. selftest.html runs the page's own checks.

Using it

/plugin marketplace add groot99-droid/Pipelines-Plugin
/plugin install rosw@rosw
python -I brushes/pipeline/app_server.py              # prints the URL with its token
python -I brushes/vault/tools/brush_search.py search "stipple"
python -I brushes/pipeline/brush_file.py inspect some.brush
python -m unittest discover -s brushes/pipeline/tests

What is not verified

  • No exported file has been opened in Procreate. Nothing here can prove it; only an iPad can. brushes/device-tests/ holds the test sets and a checklist for two short sittings.
  • The stroke preview in the designer is an approximation built from key names and Procreate's thumbnails, and each setting says whether the preview honours it. Many of its rules are inferred, not proven.
  • Official Procreate brushes mostly use textures bundled inside the app, which the library does not have; those brushes show Procreate's own thumbnail and no shape or grain image.
  • Brush tags are being added in batches; until a brush is tagged, search sees its name, set and computed facts only.
  • The licence of every vendor pack is recorded as unknown.
