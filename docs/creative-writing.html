Creative writing

An Obsidian vault of 63 works, and a pipeline that develops a new idea into a finished piece in the same voice. It goes one checkpoint at a time, and it only writes into the vault after you confirm.

On this page: The vault · The pipeline · Modes · Plot logic and registers · Running it · Backends and keys · Searching the vault · Skills and agents

The vault

creative-writing/vault/ is an Obsidian vault. Open that folder in Obsidian, and its settings come with it. It holds:

  • 63 works across books, novels, stories, book concepts, worldbuilding, songs, poems and prose, letters, a dream journal, characters and essays. They are verbatim transcriptions. The tools never edit them.
  • 00_INDEX.md, a ledger of all 63 works, and an _index.md per folder.
  • _Annotations/, a craft-annotation note for every work.
  • _ChunkTags/, per-passage plot, context, mood and motif tags from a closed vocabulary, so search can find a passage, not just a file.
  • _Craft/, notes on plot logic and the three registers. These are analysis written with Claude, never the author's own voice.
  • _Idea_Library/, where finished pipeline pieces land.
  • CLAUDE.md, the vault's rules: the four style modes, the do-not list, the frontmatter schema. It is the authority for anything written here.

The pipeline

  1. intake
  2. reference pull
  3. outline
  4. draft
  5. self-revision
  6. vault integration

Every stage is a checkpoint. Nothing moves on until you have reviewed the previous stage's output. The last stage additionally needs an explicit --confirm. Without it, it only prints a dry-run preview of what it would write.

StageWhat happens
intakeYour idea, the mode, and a register if you choose one
reference pullReal passages from the vault in that mode. A librarian condenses them and checks every quote against its source; one it cannot verify is marked [UNVERIFIED]
outlineThe shape of the piece. A story outline ends in a causal ledger, which is checked automatically
draftThe piece, following the mode's sentence and structure rules
self-revisionA pass against the mode's rules and the do-not list, with notes on what changed
vault integrationThe vault's own maintenance procedure: frontmatter, index entries, links. It writes only with --confirm

creative-writing/pipeline/spec.yaml is the single source of truth for the stages, prompts and per-mode rules. Both ways of running the pipeline read it, and neither keeps its own copy.

Modes

A mode is how a piece sounds. Four are implemented. Their full rules are in the vault's CLAUDE.md.

ModeIn shortLands in
essay-self-helpDirect address, an elevated abstract lexicon; claim, parable, practice, closing aphorism11_Essays/
horror-prosePlain, punchy, clipped; escalation by catalogued incident; cyclical or non-resolving endings03_Stories/
epic-fantasyThird person, past tense; cosmology in a codex register; converging ensembles and soul-bonds03_Stories/
confessional-poetryFirst person, autobiographical; anaphora, rhetorical questions, an aphoristic last line07_Poems_and_Prose/

unclassified is deliberately a stub. A piece there means the pipeline asks you which register you want, rather than guessing.

Plot logic and registers

A story is a chain of but and therefore, never and then. A story outline ends with a causal ledger: one row per beat, each naming the earlier beat it depends on and quoting a phrase from what that beat changed. plot_logic.py checks that the phrase is really there, that the chain has the right shape, and that the ending is legal for the mode. A failing ledger gets one automatic repair pass. The checker cannot judge whether a link is true; that is for you at the outline checkpoint.

A register is what kind of world the piece runs in, laid over any mode. It adds one tracked column to the ledger and a few shape rules. It is never inferred; you choose it.

RegisterThe worldTracks
liminalA threshold crossed and held; the surface stays ordinary and the rules do notPlace
psychedelicPerception dissolves and reforms; the way out is a surrender or a choice, never a fixSelf
cosmicA ladder of knowledge (anomaly, pattern, scale, implicated) that only risesKnows

Running it

Inside Claude Code (recommended)

Open Claude Code in the repo and ask to develop an idea. The creative-writing-pipeline skill walks the stages with you. The heavy writing goes to a drafter subagent, and the reading to a librarian subagent. Neither can write files; only the main session writes, and only after your checkpoints. This path needs no API key.

The standalone script

# start a run: note the run-id it prints
python creative-writing/pipeline/run_pipeline.py new --mode horror-prose --register cosmic --idea "..."

# review each stage's file in runs/<run-id>/, then move on
python creative-writing/pipeline/run_pipeline.py continue <run-id>

# the last stage: preview, then write into the vault
python creative-writing/pipeline/run_pipeline.py continue <run-id>
python creative-writing/pipeline/run_pipeline.py continue <run-id> --confirm

python creative-writing/pipeline/run_pipeline.py status <run-id>

If a stage fails, for example because Ollama is not running or a key is missing, the run's state is left untouched. Fix it, and run the same continue again.

Backends and keys

BackendWhere it runsKey
nativeClaude itself, inside a Claude Code session, through the skillNone
local (ollama)The script's default. Fully offline with Ollama (ollama pull llama3.1:8b)None
anthropicThe Anthropic API. Set PIPELINE_LLM_BACKEND=anthropic and pip install anthropicANTHROPIC_API_KEY
mcp (gemini_mcp)Google Gemini. Set PIPELINE_LLM_BACKEND=gemini_mcp and/or LIBRARIAN_BACKEND=gemini_mcp, and pip install google-genaiGEMINI_API_KEY

Put keys in with python docs/setup_keys.py (see Keys). llm.py reads them from ~/.rosw/keys.env. The Anthropic and Gemini backends send vault text to that provider's API.

CPU-only local inference is slow. Expect one to several minutes per librarian call with llama3.1:8b on modest hardware.

Searching the vault

A dependency-free TF-IDF search over the works, the index, annotations and craft notes. It needs no network and no packages.

python creative-writing/vault/tools/vault_search.py search "drowning" --top 5
python creative-writing/vault/tools/vault_search.py index      # rebuild after any content change

Use it before writing in a mode, before reusing a motif, or to answer "have I written about X?". Results cite a file and line range. A [craft] result is analysis, not the author's prose.

Checking it

python -m unittest discover -s creative-writing/pipeline/tests

The tests check every ledger in _Craft/ against its declared verdict, and every quotation there against the vault.
